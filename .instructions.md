# Kirikiri Grav CMS - Serveri dokumentatsioon ja haldus

See dokument kirjeldab Kirikiri veebilehe seadistust serveris ja haldustoiminguid.

Peamine arendus toimub läpakas, asi ise jookseb serveris.

## Serveri keskkond
- **Grav Versioon**: v1.8.0-beta.29
- **Admin Versioon**: v1.11.0-beta.3
- **Konteineri nimi**: `kirikiri-production`
- **Port**: 8080 (kaardistatud konteineri porti 8080)
- **Asukoht**: `/home/meelis/koduserver/kirikiri-grav` (või sarnane)

## Docker Compose Seadistus
Veebileht jookseb osana suuremast Docker Compose pinu (stack) lahendusest, mis asub ülemkaustas. Siin kaustas olevad failid (`Dockerfile`) on kasutusel pildi ehitamiseks.

**NB!** Kuna Dockerfile kasutab nüüd turvalisuse kaalutlustel porti 8080, peab ka `docker-compose.yml` kaardistama 8080:8080 (varem oli 8080:80).

**Ülemkausta `docker-compose.yml` (väljavõte):**
```yaml
services:
  # --- GRAV (Custom Build) ---
  kirikiri:
    build: 
      context: ./kirikiri-grav
    container_name: kirikiri-production
    restart: unless-stopped
    ports:
      - "8080:8080" # <-- MUUDETUD: 8080:8080
    volumes:
      - ./kirikiri-grav:/var/www/html
    extra_hosts:
      - "host.docker.internal:host-gateway"
```

## Haldustoimingud

### Koodi ja sisu uuendamine
Me oleme seadistanud serveris õigused nii, et nii kasutaja `meelis` kui ka veebiserver (`www-data`) saavad faile muuta ilma pideva `chown`-ita.

**Eelduseks on tehtud ühekordne seadistus:**
1. Kasutaja `meelis` on grupis `www-data` (`sudo usermod -aG www-data meelis`).
2. Kausta omanik on `meelis:www-data`.
3. Kaustadel on "setgid" bit (`chmod g+s`), et uued failid päriksid grupi `www-data`.

**Uuendamise workflow:**

1. **Tõmba uuendused (alamkaustas):**
   ```bash
   cd /home/meelis/koduserver/kirikiri-grav
   git pull
   ```
   *(Kui tekib "Permission denied", siis vaata allpool "Õiguste parandamine")*

2. **Uuenda konteinerit (ülemkaustas):**
   ```bash
   cd /home/meelis/koduserver
   docker compose build kirikiri
   docker compose up -d kirikiri
   ```

3. **Tühjenda vahemälu:**
   ```bash
   # Seda käsku võib jooksutada kuskohast iganes, kui ollakse samas masinas
   docker exec kirikiri-production bin/grav clearcache
   ```

### Õiguste parandamine (Fix Permissions)
Kui mingil põhjusel (nt uued failid loodud valesti) tekivad õiguste probleemid, siis taasta korrektne seis järgmiste käskudega:

```bash
# 1. Määra omanikuks meelis ja grupiks www-data
sudo chown -R meelis:www-data /home/meelis/koduserver/kirikiri-grav

# 2. Anna grupile kirjutusõigus (kaustad 775, failid 664)
# NB! See eemaldab kõigilt failidelt käivitusõiguse (+x)
sudo find /home/meelis/koduserver/kirikiri-grav -type d -exec chmod 775 {} +
sudo find /home/meelis/koduserver/kirikiri-grav -type f -exec chmod 664 {} +

# 2.1 TAASTA KÄIVITUSÕIGUSED SKRIPTIDELE (VÄGA OLULINE!)
sudo chmod +x /home/meelis/koduserver/kirikiri-grav/bin/*

# 3. Määra setgid bit (tuleviku failidele)
sudo chmod -R g+s /home/meelis/koduserver/kirikiri-grav

# 4. Vahel aitab Gitil neid muudatusi ignoreerida
cd /home/meelis/koduserver/kirikiri-grav
git config core.fileMode false
```

### Nginx Proxy (Serveris)
Serveris on Nginx seadistatud suunama `kirikiri.eu` päringud kohalikku porti `8080`.

## Probleemide lahendamine

### Pildid ei ilmu (Katkine link)
Kontrolli failinimesid:
- **Väldi tühikuid** (kasuta kriipse `-` või alakriipse `_`).
- Väldi täpitähti ja erisümboleid.
- Näide: `Screenshot from 2025.png` -> `screenshot-2025.png`.

### Piltide optimeerimine (WebP)

Teema kasutab automaatset piltide optimeerimist:
- **Sisupildid (Markdown):** `kirikiri.php` lisab automaatselt `?width=800&derivative=webp`.
- **Mallipildid (Twig):** Kasutame `.derivative('webp').resize(800).html()` meetodit.

**OLULINE:** Grav'i Twig mallides meediaobjektide puhul:
```twig
{# ❌ EI TÖÖTA - .url ei rakenda transformatsioone #}
{{ post.media[post.header.image].derivative('webp').resize(800).url }}

{# ✅ TÖÖTAB - .html() rakendab kõik transformatsioonid #}
{{ post.media[post.header.image].derivative('webp').resize(800).html('', post.title, 'card-image')|raw }}
```

`.html()` meetodi parameetrid: `html(title, alt, class)`
