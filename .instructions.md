# Server Documentation and Instructions

## Server Environment
- **Grav Version**: v1.8.0-beta.29
- **Admin Version**: v1.11.0-beta.3
- **Container Name**: `kirikiri-production`
- **Port**: 8080 (mapped to container 80)

## Docker Compose Configuration
The server runs on a custom Docker Compose setup that includes Grav, VSFTpd (for Reolink cameras), and Cloudflare DDNS.

```yaml
services:
  # --- GRAV (Custom Build) ---
  kirikiri:
    build: 
      context: ./kirikiri-grav    # Dockerfile location
    container_name: kirikiri-production
    restart: unless-stopped
    ports:
      - "8080:80"        # Grav listening on port 8080
    volumes:
      - ./kirikiri-grav:/var/www/html
    extra_hosts:
      - "host.docker.internal:host-gateway"

  # --- FTP SERVER FOR CAMERAS ---
  ftp:
    image: fauria/vsftpd
    restart: always
    ports:
      - "20:20"
      - "21:21"
      - "21100-21110:21100-21110"
    environment:
      - FTP_USER=reolink
      - FTP_PASS=xxxxxxx # SET YOUR PASSWORD HERE
      - PASV_ADDRESS=ftp.kirikiri.eu
      - PASV_ADDR_RESOLVE=YES
      - PASV_MIN_PORT=21100
      - PASV_MAX_PORT=21110
      - FILE_OPEN_MODE=0777
      - LOCAL_UMASK=000
    volumes:
      - ./kaamerad:/home/vsftpd/reolink

  # --- CLOUDFLARE DDNS (FOR FTP) ---
  ddns:
    image: oznu/cloudflare-ddns:latest
    restart: always
    environment:
      - API_KEY=xxxxxx # SET YOUR CLOUDFLARE TOKEN HERE
      - ZONE=kirikiri.eu
      - SUBDOMAIN=ftp
      - PROXIED=false
```

## Grav Administration Commands

### Clearing Cache
For Grav 1.8+ Beta versions, use `clearcache` (without hyphen).

**Command:**
```bash
docker exec -it kirikiri-production bin/grav clearcache
```

**Alternative (if permissions issue):**
```bash
docker exec -it kirikiri-production php bin/grav clearcache
```
