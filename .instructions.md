# Kirikiri Grav CMS – serveri seadistus ja haldus

## TÄHTIS!!!
Peamine arendus toimub läpakas (kohalikult), asi ise jookseb serveris (NUC).

## Serveri keskkond
- **Grav**: 2.2.x (admin2 + api pluginad; vana `admin` pluginat enam pole)
- **Konteineri nimi**: `kirikiri-production` (Apache + PHP 8.3, Apache kuulab porti 8080)
- **Asukoht**: `/home/meelis/koduserver/kirikiri-grav`
- **Hosti port**: `127.0.0.1:8080` – ainult kohalikuks testiks

## Docker Compose
Konteinerit EI käivitata siit kaustast. Teenus on kirjas ülemkausta
`/home/meelis/koduserver/docker-compose.yml`-is; siinset `Dockerfile`-i
kasutatakse ainult pildi ehitamiseks.

```yaml
  kirikiri:
    build:
      context: ./kirikiri-grav
    container_name: kirikiri-production
    restart: unless-stopped
    ports:
      - "127.0.0.1:8080:8080"
    volumes:
      - ./kirikiri-grav:/var/www/html
```

## Avalik ligipääs (Cloudflare Tunnel)
Nginxi pole. `kirikiri.eu` ja `www.kirikiri.eu` tulevad Cloudflare Tunneli
kaudu: konteiner `cloudflared` on samas Dockeri võrgus (`koduserver_default`)
ja suunab aadressile `http://kirikiri-production:8080`. Ingress on Cloudflare
dashboardis (Zero Trust → Networks → Tunnels), mitte failis.

Külastaja IP võetakse päisest `CF-Connecting-IP`
(`user/config/system.yaml`: `http_x_forwarded.cf_connecting_ip: true`,
`ip: false`). `X-Forwarded-For` esimest kirjet ei tohi usaldada – selle saab
klient ise saata.

## Haldustoimingud

### Koodi ja sisu uuendamine
1. **Tõmba uuendused:**
   ```bash
   cd /home/meelis/koduserver/kirikiri-grav
   git pull
   ```
2. **Kui `Dockerfile` muutus, ehita konteiner uuesti (ülemkaustas):**
   ```bash
   cd /home/meelis/koduserver
   docker compose build kirikiri
   docker compose up -d kirikiri
   ```
3. **Tühjenda vahemälu:**
   ```bash
   docker exec kirikiri-production bin/grav clearcache
   ```
   Käsk on `clearcache`, mitte `clear-cache`.

### Gravi tuuma ja pluginate uuendamine
1. Varukoopia enne (privaatfailid on `www-data` 0600, seega `tar` konteineris):
   ```bash
   docker exec -u www-data kirikiri-production tar czf - user > grav-pre-X.tar.gz
   ```
2. Uuendus:
   ```bash
   docker exec -u www-data kirikiri-production bin/gpm self-upgrade -y
   docker exec -u www-data kirikiri-production bin/gpm update -y
   docker exec -u www-data kirikiri-production bin/grav clearcache
   ```
3. **`git status` kohe pärast** – self-upgrade kirjutab üle meie `README.md` ja
   `.env.example` (taasta `git checkout`-iga). Major-uuendus võib kustutada ka
   `.gitignore`-i ja `robots.txt`-i.
4. Kontrolli päris lehti läbi Cloudflare'i (`/et`, `/et/blog`, `/admin`) ja et
   `/user/config/system.yaml` annab 403.
5. Uuendus muudab tavaliselt `.htaccess`-i (turvaparandused, nt `RemoveHandler .var`)
   ja `user/config/versions.yaml`-i – vaata `git diff .htaccess` üle ja commit'i
   mõlemad.

### Failide õigused
Kasutaja `meelis` on grupis `www-data`, kaustal on setgid bit, nii et uued
failid pärivad grupi `www-data`. Gravi uuendused jätavad osa faile
`www-data:www-data 644` – neid saab muuta konteineri kaudu
(`docker exec -u www-data kirikiri-production ...`) või õigused taastades:

```bash
sudo chown -R meelis:www-data /home/meelis/koduserver/kirikiri-grav
sudo find /home/meelis/koduserver/kirikiri-grav -type d -exec chmod 2775 {} +
sudo find /home/meelis/koduserver/kirikiri-grav -type f -exec chmod 664 {} +
sudo chmod +x /home/meelis/koduserver/kirikiri-grav/bin/*   # VÄGA OLULINE
cd /home/meelis/koduserver/kirikiri-grav && git config core.fileMode false
```

**NB:** `user/config/security-private.php` ja `user/config/plugins/*-private.php`
peavad jääma `www-data` 0600 – pärast ülaltoodud käske:
```bash
sudo chown www-data user/config/security-private.php user/config/plugins/*-private.php
sudo chmod 600 user/config/security-private.php user/config/plugins/*-private.php
```

## Probleemide lahendamine

### Pildid ei ilmu (katkine link)
- **Väldi tühikuid** failinimedes (kasuta `-` või `_`).
- Väldi täpitähti ja erisümboleid.
- Näide: `Screenshot from 2025.png` → `screenshot-2025.png`.

### Piltide optimeerimine (WebP)
- **Sisupildid (Markdown):** `kirikiri.php` lisab automaatselt `?width=800&derivative=webp`.
- **Mallipildid (Twig):** `.derivative('webp').resize(800).html()`.

**OLULINE:** Twig mallides meediaobjektide puhul:
```twig
{# ❌ EI TÖÖTA - .url ei rakenda transformatsioone #}
{{ post.media[post.header.image].derivative('webp').resize(800).url }}

{# ✅ TÖÖTAB - .html() rakendab kõik transformatsioonid #}
{{ post.media[post.header.image].derivative('webp').resize(800).html('', post.title, 'card-image')|raw }}
```
`.html()` parameetrid: `html(title, alt, class)`.

### Adminis puudub mallivalik või Featured Image väli
Aegunud vahemälu – tühjenda: `docker exec kirikiri-production bin/grav clearcache`.
